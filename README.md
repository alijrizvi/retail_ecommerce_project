# Retail & E-Commerce: American Football Sales Analysis & Modeling

A comprehensive project analyzing merchandise sales data for American Football products from physical stores (in-person) and e-commerce (online). Machine Learning models were also built to help make business decisions and perform predictive modeling for the future.
This project was completed with a Data Scientist's approach and skill set, integrating Generative AI tools for task augmentation as well.

## Data Collection
The original datasets used in this project were obtained from Kaggle, via Novice "Larisa" (https://www.kaggle.com/larysa21).

## Conclusions
After data collection and organization, data cleaning and wrangling, data visualization, and machine learning across Python and SQL (Postgres), final Hypothesis Testing (A/B Testing) was performed to ascertain whether online or in-person platforms yielded the best selling opportunities.
